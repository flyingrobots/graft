# v0.12.0

## Summary

v0.12.0 establishes the authority-safe inner boundary required for Graft's
future Echo-hosted workspace observations. Graft can analyze an admitted,
immutable set of workspace bytes without silently falling back to the live
filesystem, and its structural review surfaces now carry substantially more
precise cross-language reference evidence.

This is not yet the production Echo cutover. Production still observes live
workspace bytes; the retained Edict request, Echo settlement, restart, and
zero-reread replay vertical remains the next architecture milestone.

## What Changed

- Added `graft_import_diagnostics` and `graft struct import-diagnostics` for
  structured first-party import-shadow evidence.
- Added cross-language qualified-reference resolution and explicit partial
  confidence across Python, TypeScript/JavaScript, Rust, and Go.
- Added an immutable admitted workspace-read authority with fail-closed root,
  path aperture, symlink, byte-budget, encoding, and mutation checks.
- Routed governed outline, range, code-show, and changed-since behavior through
  consistent workspace-read authority and observation semantics.
- Versioned expanded `file_outline` and structural-review response contracts as
  `2.0.0` while leaving unrelated contracts unchanged.
- Isolated per-request workspace activation and added requested-workspace
  routing groundwork for multi-worktree correctness.
- Split CI so Node 20 runs package compatibility smoke and Node 22 owns the
  release-grade Docker-isolated suite.
- Updated vulnerable transitive dependencies so the release graph has no known
  high or critical npm advisories.

## Why It Matters

Echo can only preserve trustworthy workspace evidence if Graft already refuses
authority ambiguity and can consume settled bytes without rereading mutable
disk state. This release makes that inner boundary real. It also improves
review truth today by distinguishing exact committed-reference evidence from
partial fallback evidence instead of manufacturing confident zeros.

## Breaking Changes

No package entry point was removed. Strict consumers of the changed
`file_outline` and structural-review response envelopes must recognize their
new `2.0.0` schema versions and added fields.

## Migration

- Update strict response-schema allowlists for the two `2.0.0` contracts.
- No CLI command, MCP tool name, or library import migration is otherwise
  required.

## Known Limits

- Production composition still uses `LiveWorkspaceReadSource`.
- Graft does not yet declare or submit `ObserveWorkspaceSnapshot` through
  Edict, decode a retained Echo settlement, or replay after restart with zero
  filesystem reads.
- Issue #238 still needs the exact two-worktree `graft_since` proof and explicit
  requested/resolved-root response contract.
- git-warp remains the normal structural-history backend; this release does not
  claim `echo-native` production evidence.
