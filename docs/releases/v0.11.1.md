# v0.11.1

## Summary

v0.11.1 is a release-governance patch. It publishes the agent guidance needed
to inspect Graft's tag-triggered release workflow correctly and to keep release
authority anchored to version tags on `main`.

This release does not change Graft's CLI, MCP server, library API, projection
contracts, package contents, or runtime behavior.

## What Changed

- `AGENTS.md` now tells operators to inspect `.github/workflows/release.yml`,
  release run/job state, job logs, GitHub Release assets, and npm registry state
  instead of inferring publish progress from coarse waiting.
- `AGENTS.md` now states the release invariant explicitly: merge release-prep
  work to `main`, tag that `main` commit with the release version, push the tag,
  and let GitHub Actions deploy from the tag.
- The release packet records `0.11.1` as a patch release so downstream users can
  consume the corrected release-governance guidance from a published package.

## Why It Matters

The release workflow is tag-triggered and checks that the pushed tag version
matches `package.json`. Publishing from a release branch, pull request head, or
untagged commit would bypass the intended authority model. This patch makes the
correct workflow explicit for future operators.

## Breaking Changes

None.

## Migration

No migration is required.

## Known Limits

- This patch does not change any runtime code.
- This patch does not alter npm trusted publishing or GitHub Actions workflow
  definitions.
